No additional maintainer or collaborator role is assigned by this document.
The Git history records individual code contributions. Recognition does not
imply repository write access or responsibility for every release.

New collaborators are listed after they agree to the attribution and scope.
Repository permissions must be granted separately. Changes to ownership or
release authority require maintainer review and a CODEOWNERS update.

See [CONTRIBUTING.md](CONTRIBUTING.md) to contribute and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for participation expectations.
