# Code of Conduct

## Scope and expectations

This policy applies to project issues, pull requests, discussions, reviews,
and other spaces where participants represent FeROS Builder.

Treat participants respectfully. Critique code and decisions with evidence.
Accept technical disagreement, respect privacy, and make room for contributors
with different backgrounds and levels of experience.

Harassment, threats, discriminatory abuse, sexual harassment, disclosure of
private personal information, and sustained disruption are unacceptable.

## Reporting

A private conduct-reporting contact has not yet been designated. The maintainer
must publish an agreed contact here before the first public release.
Do not post sensitive allegations or personal information in public issues.
GitHub's platform reporting tools remain available for violations of its rules;
they are not a substitute for a project-specific reporting channel.

## Enforcement

The maintainer may remove inappropriate material, request corrections, restrict
participation, or remove project access according to the severity and pattern
of behavior. Decisions should be proportionate and based on available evidence.
Reports should be shared only with those needed to handle them; absolute
confidentiality cannot be promised. No response deadline is guaranteed.

Participants may request reconsideration through the designated private
contact once established. The project currently has one maintainer and cannot
promise an independent appeal panel. A report involving that maintainer needs
an alternative agreed reviewer; none has yet been appointed.

This is a project-specific policy, not an adoption of a named external code.
